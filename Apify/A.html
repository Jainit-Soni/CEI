Project Definition

College & Exam Intelligence (CEI)

An India-focused education data infrastructure project designed to build a truthful, official-source-based data system for Indian colleges, universities, institutes, exams, counselling systems, seat matrices, cutoffs, fees, placements, approvals, accreditations, rankings, and related education signals.

🚫

Not a Listing Task

This is not a generic college listing or content writing assignment. We do not generate text descriptions.

🏢

Official Data Only

Canonical truth comes only from official domains (AISHE, AICTE, UGC, NAAC, NIRF, JoSAA, etc.).

📦

Strict Deliverables

Returns either CEI_REAL_OFFICIAL_DATA.zip or CEI_BLOCKER_REPORT.zip. No fake success.

🛡️

The Truth Policy (Non-Negotiable)

The CEI infrastructure is strictly governed by a zero-tolerance policy for fabricated, guessed, or unofficial data. If official sources disagree, both values are kept in a conflicts registry.

✖ never guess
✖ never fabricate rows
✖ never generate fake production data
✖ never create mock/sample/demo records
✖ never use unofficial aggregators as truth
✖ never convert missing values to inferred
✖ never silently overwrite conflicts
✔ always preserve provenance
✔ always prefer truth over coverage
